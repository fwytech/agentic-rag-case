# Agentic RAG 实战教程导航

## 📖 课程概览

欢迎来到 Agentic RAG 实战教程！

本教程将带你从零开始，深入理解 Agentic RAG 技术，并通过三个完整项目的手把手实践，最终掌握如何构建生产级智能问答系统。

**课程特色：**
- 📚 **理论扎实**：从 RAG 演进到 ReAct 框架的完整理论体系
- 💻 **实战导向**：每讲都包含完整可运行的代码
- 🎯 **循序渐进**：从简单到复杂，从理论到生产
- 🔧 **生产就绪**：最终交付三个可直接使用的完整项目

**学习周期：** 建议 2-4 周
**总课时：** 18 讲
**难度级别：** 入门 → 进阶 → 生产

## 💡 学习建议

### 1. 理论先行

**第1-2讲是基础**，务必认真学习：
- 理解为什么需要 RAG
- 理解 ReAct 框架的工作原理
- 理解传统 RAG 和 Agentic RAG 的本质区别

### 2. 动手实践

**每讲的代码都要亲自敲一遍**：
- 不要复制粘贴
- 理解每一行代码的作用
- 尝试修改参数看效果

### 3. 对比理解

**重点理解差异**：
- 传统 RAG vs Agentic RAG
- 简单查询 vs 复杂查询
- 本地模型 vs 在线模型

### 4. 循序渐进

**不要跳跃学习**：
- 基础不牢，地动山摇
- 每个概念都要理解透彻
- 遇到问题及时复习前面的内容

### 5. 举一反三

**学以致用**：
- 思考如何应用到自己的项目
- 尝试添加新的工具
- 优化系统性能

1. **Q: 需要什么前置知识？**
   - A: Python 基础、了解 LLM 概念即可，会逐步引入其他知识

2. **Q: 代码运行出错怎么办？**
   - A: 检查依赖版本、环境变量配置、查看教程中的故障排查部分

3. **Q: 没有 GPU 可以学习吗？**

4. **Q: 学完能做什么？**
